01 · FEATURED PROJECT

QR Token Management & Validation App

A customized Android application I personally developed for an institute to create, print, validate, and expire physical QR discount tokens.

JavaAndroidFirebaseQR

How it works

Administrators can create batches of unique QR tokens directly from the app and print them on paper with the institute's information. The token carries a unique number that is used by the backend for validation.

Validation & expiry

When an authorized user scans a token, the app reads its unique number and checks Firebase. If the token exists and is still active, the app confirms that it is valid and provides the authorized user with the option to destroy it. Once destroyed, the token is marked as expired in the backend and cannot be reused.

Admin creates token→Token printed on paper→Authorized user scans→Firebase validates→Token destroyed / expired
